Política de Privacidad — Extensión Tucuy

Última actualización: octubre 2026

1. Información que recopilamos

La extensión Tucuy no recopila ni almacena ningún dato personal del usuario. No recopilamos nombres, correos electrónicos, contraseñas, datos de ubicación ni ningún otro identificador personal.

2. Cómo funciona la extensión

Cuando el usuario selecciona un texto, enlace o imagen para verificar, ese contenido se envía temporalmente al servidor de análisis de Tucuy (tucuy-backend.onrender.com) únicamente para procesar el análisis de desinformación. El contenido enviado:

  • No se almacena de forma permanente en ningún servidor.
  • No se comparte con terceros.
  • Se descarta inmediatamente después de generar el resultado del análisis.

3. Permisos utilizados

  • activeTab: Para leer el contenido seleccionado por el usuario en la pestaña activa.
  • contextMenus: Para mostrar la opción "Verificar con Tucuy" al hacer clic derecho.
  • storage: Para guardar preferencias locales del usuario en su propio navegador.
  • notifications: Para mostrar resultados cuando el panel no está disponible.

4. Cookies y rastreo

La extensión Tucuy no usa cookies, no rastrea la navegación del usuario y no genera perfiles de comportamiento.

5. Seguridad

Toda comunicación entre la extensión y el servidor de análisis se realiza mediante HTTPS. No transmitimos datos sensibles como contraseñas, datos bancarios ni información personal.

6. Cambios a esta política

Si realizamos cambios significativos a esta política, actualizaremos esta página. El uso continuado de la extensión implica la aceptación de la política vigente.

7. Contacto

Para preguntas sobre esta política de privacidad, puedes contactarnos a través del repositorio del proyecto en GitHub: github.com/MeAnd17/anti-desinformacion
